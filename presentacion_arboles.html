¿Qué es un Árbol?

Un árbol es una estructura de datos no lineal con relaciones jerárquicas entre sus elementos, sin contener ciclos.

Utilidad de los Árboles

  • Jerarquía Natural: Perfectos para representar sistemas de archivos (carpetas y archivos), el DOM de HTML o estructuras organizacionales.
  • Búsqueda Eficiente: Permiten búsquedas, inserciones y eliminaciones en O(log n), superando a las listas ligadas.
  • Inteligencia Artificial: Árboles de decisión en Machine Learning o árboles de juego (Minimax en Ajedrez).
  • Bases de Datos: Los índices de las bases de datos SQL utilizan árboles B o B+ para buscar registros rápidamente.

Terminología, Altura y Profundidad

  • Nodo: Elemento del árbol.
  • Raíz (Root): El nodo superior, sin padres.
  • Hoja (Leaf): Un nodo sin hijos.
  • Profundidad (Depth): Longitud del camino desde la Raíz hasta un nodo específico.
  • Altura (Height) del nodo: Longitud del camino más largo desde el nodo hasta una hoja.
  • Altura del árbol: La altura de la Raíz.

Árbol Binario de Búsqueda (ABB)

Un Árbol Binario es aquel donde cada nodo tiene máximo 2 hijos. Un ABB añade una regla fundamental:

Todo hijo a la IZQUIERDA es MENOR que su padre.
Todo hijo a la DERECHA es MAYOR que su padre.

Esta propiedad permite descartar la mitad del árbol en cada paso de búsqueda, simulando una búsqueda binaria dinámica.

Estructura del Código (Java)

Primero, definimos la clase Nodo.

class Nodo {
    int dato;
    Nodo izquierdo;
    Nodo derecho;

    public Nodo(int dato) {
        this.dato = dato;
        this.izquierdo = null;
        this.derecho = null;
    }
}

Código: Método Insertar

Usamos recursividad para viajar por el árbol hasta encontrar un espacio vacío.

public Nodo insertarRecursivo(Nodo actual, int valor) {
    if (actual == null) {
        return new Nodo(valor);
    }

    if (valor < actual.dato) {
        actual.izquierdo = insertarRecursivo(actual.izquierdo, valor);
    } else if (valor > actual.dato) {
        actual.derecho = insertarRecursivo(actual.derecho, valor);
    }

    return actual;
}

Código: Método Buscar

Aprovechamos la propiedad del ABB para descartar subárboles enteros.

public boolean buscar(Nodo actual, int valor) {
    if (actual == null) return false;
    
    if (actual.dato == valor) return true;
    
    if (valor < actual.dato) {
        return buscar(actual.izquierdo, valor);
    } else {
        return buscar(actual.derecho, valor);
    }
}

Paso a Paso: Recorridos (Traversals)

Formas de visitar los nodos en Búsqueda en Profundidad (DFS).

1. Pre-Orden (Raíz ➔ Izq ➔ Der)
Uso: Clonar el árbol.
40 ➔ 20 ➔ 10 ➔ 30 ➔ 60
2. In-Orden (Izq ➔ Raíz ➔ Der)
Uso: Obtener datos ordenados.
10 ➔ 20 ➔ 30 ➔ 40 ➔ 60
3. Post-Orden (Izq ➔ Der ➔ Raíz)
Uso: Eliminar el árbol (borras hijos primero).
10 ➔ 30 ➔ 20 ➔ 60 ➔ 40

Orden Espacial y Temporal (Big O)

Operación Promedio (Balanceado) Peor Caso (Desbalanceado)
Búsqueda O(log n) O(n)
Inserción O(log n) O(n)
Eliminación O(log n) O(n)
Orden Espacial: O(n). Cada nodo requiere memoria para el dato y los dos punteros (izquierdo y derecho).

¿Cuándo usar un Árbol (ABB)?

✅ CUÁNDO USARLO

  • Datos que deben mantenerse ordenados constantemente.
  • Búsquedas repetitivas muy rápidas en conjuntos de datos dinámicos.
  • Implementación de Diccionarios o Mapas (TreeMap en Java).

❌ CUÁNDO NO USARLO

  • Datos Pequeños: Un array simple es más rápido por localidad de caché.
  • Si solo necesitas el máximo/mínimo repetidamente (usa Cola de Prioridad/Heap).
  • Si el acceso es por índices (ej. obtener el elemento en la posición 5).

Errores Comunes en Código

  • NullPointerException: Intentar hacer nodo.izquierdo.dato sin verificar si nodo.izquierdo == null.
  • Ignorar el Balanceo: No usar variantes como AVL o Red-Black Tree. Si insertas datos ordenados, el árbol rinde como lista O(n).
  • Pérdida de la Raíz: Modificar la variable raiz accidentalmente durante una iteración.
  • Borrado Incorrecto: Al eliminar un nodo con dos hijos, no buscar el sucesor correcto.

Árbol a Lista Ligada

¿Sabías que un Árbol Binario de Búsqueda puede transformarse en una Lista Doblemente Ligada Ordenada usando sus mismos punteros?

  • Concepto: Reutilizamos el puntero izquierdo como prev y derecho como next.
  • ¿Cómo se hace? Realizando un recorrido In-Orden y reasignando los enlaces al visitar cada nodo.
  • Ventaja Espacial: Transformación In-Place sin crear nuevos objetos en memoria.
